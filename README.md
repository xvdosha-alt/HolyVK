# HolyVK

Расширение для браузера: показывает никнеймы сотрудников из [journal.holyworld.me](https://journal.holyworld.me) прямо в списке чатов VK.

## Возможности

- Подпись ника рядом с именем в VK Messenger
- Подсказка с должностью при наведении
- Кэш списка сотрудников на 10 минут
- Автообновление при перезагрузке вкладки VK и по таймеру в фоне

## Структура

```
chrome/    — Chrome и Chromium-браузеры
firefox/   — Firefox
yandex/    — Яндекс.Браузер
```

## Установка (Chrome / Яндекс)

1. Открой `chrome://extensions` (или `browser://extensions` в Яндекс.Браузере).
2. Включи **Режим разработчика**.
3. Нажми **Загрузить распакованное расширение** и выбери папку `chrome/` или `yandex/`.

## Установка (Firefox)

1. Открой `about:debugging#/runtime/this-firefox`.
2. Нажми **Загрузить временное дополнение**.
3. Выбери `firefox/manifest.json`.

## API

Расширение запрашивает:

```
GET https://journal.holyworld.me/srv/api/v1/staff
```

Доступ нужен только модераторам с правами на журнал.

## Версия

Текущая версия указана в `manifest.json` каждого варианта (`1.0.0`).
